# Changelog

## v0.2
### v0.2.1
* Reworked the Makefile, to start supporting broader building capabilities,
* Backported "New Project" and "Colors" dialogs from earlier internal iterations of Dimension,
* Now the new project is required to create by default (will be regulable later),
* Introduced video exporter, based on Windows Media Foundation which renders a `.mp4` file,
* Minor bugfixes and quality of life improvements.

### v0.2.0
* Implemented Direct2D rendering engine on the EngineV2,
* Introduced activity history, which can be regulated with Undo (Ctrl+Z) and Redo (Ctrl+Y) buttons,
* Added ability to extend existing frames (press F5 for such),
* Extended Help section to include direct links to the Wiki and Changelog,
* Fixed the bug with dark theme appearance on Windows 10.

## v0.1
* Initial release.
